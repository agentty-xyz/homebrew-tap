# Agentty Homebrew Tap

Homebrew formulas for [Agentty](https://github.com/agentty-xyz/agentty) and its
`testty` TUI testing CLI.

```sh
brew install agentty-xyz/tap/agentty
brew install agentty-xyz/tap/testty
```

Update with `brew upgrade agentty` or `brew upgrade testty`.

The formulas in `Formula/` are generated by `ag-release` and pushed by the
Agentty release workflow for every stable release; do not edit them here.
